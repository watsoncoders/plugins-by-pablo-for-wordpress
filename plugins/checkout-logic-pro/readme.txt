Conditional WooCommerce checkout fields and payment method rules.

== Description ==

Checkout Logic Pro adds focused checkout rules without requiring a large rules engine.

Features:
* Hide company field below a subtotal.
* Hide order notes below a subtotal.
* Require billing phone over a subtotal.
* Disable Cash on Delivery above a subtotal.
* Disable bank transfer below a subtotal.

== Installation ==

1. Upload and activate the plugin.
2. Go to WooCommerce > Checkout Logic.
3. Configure the thresholds. Use 0 to disable a rule.
