Reduce risky WooCommerce cash-on-delivery orders with limits, blocklists and optional surcharge.

== Description ==

Features:
* Maximum order total for COD.
* Optional COD surcharge.
* Blocklists for email, phone and IP address.
* Checkout validation.
* Risk notes on COD orders.

== Installation ==

1. Upload and activate the plugin.
2. Go to WooCommerce > COD Risk Guard.
3. Configure your rules.
